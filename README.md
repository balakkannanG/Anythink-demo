# anyTHINK Media & Events

A five-route Next.js 15 and Tailwind CSS v4 marketing site translated from the supplied anyTHINK Media & Events deck.

## Routes

- `/` — Home
- `/about` — Who We Are
- `/services` — What We Do
- `/work` — Our Work
- `/contact` — Contact

## Local development

```bash
npm run dev
```

The inquiry form currently uses a local demo submission boundary in `lib/contact.ts`. Replace it with a server action or API provider before connecting production email delivery.
